# ミストトレインガールズX (미스트트레인 걸즈 X) 한국어 패치

<p align="center"><img src="docs/banner.png" alt="미스트트레인 걸즈 X 한국어 패치" width="800"></p>

ミストトレインガールズX의 비공식 한국어 패치입니다.

## 설치
1. [Releases](../../releases/latest)에서 최신 zip을 받아 압축을 풉니다.
2. `[게임폴더에_덮어쓰기]` 안의 내용물을 게임 폴더(`MistX.exe` 가 있는 곳)에 붙여넣습니다.

- 실행 시 번역 자동 업데이트를 위해 GitHub에 접속합니다.(`BepInEx\config` 설정에서 온오프 가능)
- 제거: 게임 폴더에서 `winhttp.dll` · `doorstop_config.ini` · `BepInEx` 삭제.

## 번역 범위
| 항목 | 번역 |
|---|---|
| 메인 스토리 1~5부 | ✅ |
| 메인 스토리 6부, 사이드 스토리, 캐릭터 스토리 | ❌ |
| UI · 텍스트 (메뉴 · 아이템 · 스킬 · 캐릭터 이름 등) | ✅ |
| 이미지 속 텍스트 | ❌ |
| 동영상 | ❌ |

## 문제 보고
크래시·오류가 생기면 [Issues](../../issues/new/choose)에 **로그를 첨부해서** 보고해주세요. (`BepInEx\LogOutput.log`, `Player.log` 등 — 템플릿 안내 참고)

## 면책
팬 번역이며 개발사·배급사와 관계가 없습니다. 게임의 권리는 각 권리자에게 있습니다.
